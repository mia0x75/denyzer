    Regex engine benchmark

    Conclusion

    The benchmark measured Denyzer's real regex path, not an isolated MatchString loop:

    ChainedGroupedCache.Contains
  -> InMemoryGroupedCache.Contains
  -> regexCache.findMatch
  -> compiled regexp.MatchString

    The benchmark-backed decision is:

    1. Do not replace the standard library with go-re2. Its default WASM implementation was usually slower on Denyzer's short domain strings and substantially slower for large OISD-shaped linear scans. Its re2_cgo mode requires a system-installed RE2 library through pkg-config, which does not fit the current Zig/musl cross-build setup.
    2. Do not make coregex a blanket replacement yet. It was dramatically faster for the OISD shape ^(.*\.)?domain$, but slower than the standard library for the literal-prefix shape after the first match. It also has materially higher compile cost and retained memory, and is pre-1.0.
    3. Keep regex work in Phase 4 (blocking regex pre-filter). First avoid entering the regex cache when exact or wildcard caches can decide the query. Then remeasure the remaining regex-only path. If an engine replacement is still justified, evaluate coregex only for the measured pattern class.

    This report does not change the production regex implementation.

    Environment and method

    • Go go1.27.3-X:nodwarf5
    • Linux amd64, 16 logical threads
    • CPU governor: schedutil
    • Host otherwise idle during the formal runs
    • Fresh repository copy, including the existing go fix ./... changes
    • Engines:
    • standard library regexp
    • github.com/wasilibs/go-re2 v1.13.0
    • github.com/coregx/coregex v0.12.30
    • Three rounds with the engine order rotated between rounds; values below are medians of the three observations.
    • The scratch selector used build tags only. No interface dispatch was added to the measured query path.

    The core command was:

    env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy \
  -u SOCKS5_PROXY \
  go test -tags "$ENGINE_TAGS" ./cache/stringcache -run '^$' \
  -bench '^BenchmarkEngine(Chain|Compile)$' -benchmem \
  -benchtime=200ms -count=1

    The tested regex counts were 1, 10, 50, 100, 500, and 1000. Query cases were first, middle, last, miss, near-miss, subdomain, exact-cache, and wildcard-cache. The two regex shapes were:

    OISD:   ^(.*\.)?domain$
Prefix: ^regexN\..*$

    An independent-process probe confirmed the retained-memory direction at 1000 OISD rules: approximately 8.5 MB RSS for stdlib, 33.5 MB for coregex, and 6.0–6.4 MB for go-re2. The go-re2 number does not mean it is free: its default implementation is a Go-translated WebAssembly RE2 runtime and its binary has additional fixed cost.

    Binary, initialization, and build checks

    Unstripped go build . sizes in the scratch copy were:

    Engine Binary size Change vs stdlib
    stdlib 37,321,584 bytes —
    coregex 38,536,808 bytes +3.3%
    go-re2 42,883,408 bytes +14.9%

    Direct GODEBUG=inittrace=1 runs showed no material explicit initializer cost. coregex adds simd, prefilter, and meta package init entries; the measured entries together were about 0.01 ms in the probe. The important go-re2 cost is its WASM runtime and binary/RSS footprint rather than a large named Go initializer.

    Representative CGO_ENABLED=0 go test -c checks passed for all three engines on linux/amd64, linux/arm64, and linux/mipsle. This confirms that the coregex non-amd64 fallback is buildable for representative targets; it is not a performance claim for those targets.

    The go-re2 re2_cgo build was tested and failed because this host has no re2.pc/system RE2 installation. The package documentation requires that system dependency, which would complicate the existing Zig cross-build and musl release path.

    Correctness and API checks

    • Differential testing compared standard-library and selected-engine results over 2,007 patterns and 6,010 query strings: 12,062,070 match checks.
    • It covered OISD and prefix rules, configured examples, empty and Unicode inputs, malformed patterns, String, MatchString, and ReplaceAllString.
    • All three variants passed the existing cache/stringcache test suite.
    • The full repository compiled with go test ./... -run '^$' for both alternatives in the scratch copy.
    • coregex documents the required drop-in methods and requires Go 1.27+, which is satisfied by the repository's current Go version. It remains pre-1.0, so API stability is an additional maintenance cost.

    Other production regex call sites (resolver/caching_resolver.go, resolver/query_logging_resolver.go, util/common.go, config/upstream.go, and lists/parsers/hosts.go) were not changed by this benchmark. A future engine change must validate those call sites separately, especially the shared *regexp.Regexp types in the caching resolver.

    Reproduction notes

    Raw benchmark outputs and the temporary harness were kept under /tmp/opencode during the experiment. Reproduce on an otherwise idle host, keep the governor at schedutil, rotate engine order between rounds, and do not run another compile or benchmark concurrently.

    Real cache-path benchmark

    This test lives in cache/stringcache, so it can use the package's actual ChainedGroupedCache, InMemoryGroupedCache, regex factory, and OISD test data.

    package stringcache

import (
    "fmt"
    "regexp"
    "runtime"
    "strings"
    "testing"

    engine "github.com/mia0x75/denyzer/internal/benchregexp"
)

// Patterns use the repository's actual OISD-derived data, in file order.
// Prefix patterns match the shape in grouped_cache_lookup_bench_test.go.
func enginePatterns(shape string, n int) ([]string, []string) {
    patterns, domains := make([]string, n), make([]string, n)
    for i := range n {
        if shape == "oisd" {
            patterns[i] = regexTestData[i]
            domains[i] = strings.TrimPrefix(wildcardTestData[i], "*.")
        } else {
            patterns[i] = fmt.Sprintf(`/^regex%d\..*$/`, i)
            domains[i] = fmt.Sprintf("regex%d.example.com", i)
        }
    }
    return patterns, domains
}

func engineChain(tb testing.TB, patterns []string) *ChainedGroupedCache {
    tb.Helper()
    c := NewChainedGroupedCache(
        NewInMemoryGroupedRegexCache(),
        NewInMemoryGroupedWildcardCache(),
        NewInMemoryGroupedStringCache(),
    )
    f := c.Refresh("default")
    for _, p := range patterns {
        if !f.AddEntry(p) {
            tb.Fatalf("entry rejected: %s", p)
        }
    }
    for i := range 200 {
        f.AddEntry(fmt.Sprintf("*.wild%d.example", i))
    }
    for i := range 5000 {
        f.AddEntry(fmt.Sprintf("string%d.example.com", i))
    }
    f.Finish()
    if got := c.ElementCount("default"); got != len(patterns)+5200 {
        tb.Fatalf("count %d", got)
    }
    return c
}

func BenchmarkEngineChain(b *testing.B) {
    for _, shape := range []string{"oisd", "prefix"} {
        for _, n := range []int{1, 10, 50, 100, 500, 1000} {
            patterns, domains := enginePatterns(shape, n)
            c := engineChain(b, patterns)
            cases := []struct{ name, domain string }{
                {"first", domains[0]},
                {"middle", domains[n/2]},
                {"last", domains[n-1]},
                {"subdomain", "a.b.c." + domains[n-1]},
                {"miss", "not-present.example.org"},
                {"near-miss", domains[n-1] + ".invalid"},
                {"short-miss", "x.io"},
                {"exact", "string1234.example.com"},
                {"wildcard", "a.wild123.example"},
            }

            // Calculate the expected rule independently with the standard library.
            refs := make([]*regexp.Regexp, len(patterns))
            for i, p := range patterns {
                refs[i] = regexp.MustCompile(p[1 : len(p)-1])
            }
            for _, tc := range cases {
                want := ""
                for _, r := range refs {
                    if r.MatchString(tc.domain) {
                        want = "/" + r.String() + "/"
                        break
                    }
                }
                if tc.name == "exact" {
                    want = tc.domain
                }
                if tc.name == "wildcard" {
                    want = "*.wild123.example"
                }

                b.Run(fmt.Sprintf("%s/n=%d/%s", shape, n, tc.name), func(b *testing.B) {
                    groups := []string{"default"}
                    if got := c.Contains(tc.domain, groups)["default"]; got != want {
                        b.Fatalf("got %q want %q", got, want)
                    }
                    b.ReportAllocs()
                    b.ResetTimer()
                    for b.Loop() {
                        _ = c.Contains(tc.domain, groups)
                    }
                })
            }
        }
    }
}

func BenchmarkEngineCompile(b *testing.B) {
    for _, shape := range []string{"oisd", "prefix"} {
        for _, n := range []int{1, 10, 50, 100, 500, 1000} {
            patterns, _ := enginePatterns(shape, n)
            b.Run(fmt.Sprintf("%s/n=%d", shape, n), func(b *testing.B) {
                b.ReportAllocs()
                for b.Loop() {
                    f := newRegexCacheFactory()
                    for _, p := range patterns {
                        if !f.addEntry(p) {
                            b.Fatal(p)
                        }
                    }
                    if f.count() != n {
                        b.Fatalf("compiled %d want %d", f.count(), n)
                    }
                    _ = f.create()
                }
            })
        }
    }
}

    Differential correctness and retained-memory checks

    The correctness test compared every selected engine against the standard library. It also checked replacement behavior because util.Obfuscate uses ReplaceAllString.

    func TestEngineDifferential(t *testing.T) {
    patterns, domains := enginePatterns("oisd", 1000)
    pp, dd := enginePatterns("prefix", 1000)
    patterns, domains = append(patterns, pp...), append(domains, dd...)
    patterns = append(patterns,
        `/.*google.com/`, `/^apple\.(de|com)$/`, `/amazon/`,
        `/(?i)example\.com$/`, `/^$/`, `/\bads\b/`, `/[a-zA-Z0-9]/`,
    )
    queries := []string{
        "", "x.io", "not-present.example.org", "EXAMPLE.COM", "apple.de",
        "www.google.com", "amazon", "ads.example", "例子.测试", "a\x00b",
    }
    for _, d := range domains {
        queries = append(queries, d, "a.b."+d, d+".invalid")
    }

    checks := 0
    for _, p := range patterns {
        p = p[1 : len(p)-1]
        ref, err := regexp.Compile(p)
        if err != nil {
            t.Fatal(err)
        }
        got, err := engine.Compile(p)
        if err != nil {
            t.Fatalf("%s compile %q: %v", engine.Engine, p, err)
        }
        if got.String() != ref.String() {
            t.Fatalf("String mismatch %q", p)
        }
        for _, q := range queries {
            if a, b := got.MatchString(q), ref.MatchString(q); a != b {
                t.Fatalf("%s pattern=%q query=%q got=%v want=%v", engine.Engine, p, q, a, b)
            }
            checks++
        }
    }

    for _, p := range []string{"*", "?", "+", "[", "(wrongRegex", `\q`} {
        _, a := regexp.Compile(p)
        _, b := engine.Compile(p)
        if (a == nil) != (b == nil) {
            t.Fatalf("compile acceptance %q: %v / %v", p, a, b)
        }
    }
    for _, p := range []string{`[a-zA-Z0-9]`, `(example)`, `^|$`} {
        a, b := regexp.MustCompile(p), engine.MustCompile(p)
        for _, q := range queries[:10] {
            for _, replacement := range []string{"*", "$1", "${1}-x"} {
                if a.ReplaceAllString(q, replacement) != b.ReplaceAllString(q, replacement) {
                    t.Fatalf("replacement mismatch %q %q", p, q)
                }
            }
        }
    }
    t.Logf("engine=%s patterns=%d queries=%d match_checks=%d", engine.Engine, len(patterns), len(queries), checks)
}

func TestEngineRetainedMemory(t *testing.T) {
    for _, shape := range []string{"oisd", "prefix"} {
        for _, n := range []int{100, 500, 1000} {
            patterns, _ := enginePatterns(shape, n)
            runtime.GC()
            var before, after runtime.MemStats
            runtime.ReadMemStats(&before)
            f := newRegexCacheFactory()
            for _, p := range patterns {
                if !f.addEntry(p) {
                    t.Fatal(p)
                }
            }
            cache := f.create()
            runtime.ReadMemStats(&after)
            if cache == nil {
                t.Fatal("empty cache")
            }
            t.Logf("engine=%s shape=%s n=%d heap_delta=%d alloc_delta=%d",
                engine.Engine, shape, n,
                after.HeapAlloc-before.HeapAlloc,
                after.TotalAlloc-before.TotalAlloc)
            _ = cache
        }
    }
}

    Independent compile/RSS probe

    The probe was built three times with the same selector tags. Running it as a separate process avoided retaining allocations from one engine or one regex count while measuring another.

    package main

import (
    "flag"
    "fmt"
    "os"
    "runtime"
    "strconv"
    "strings"
    "time"

    "github.com/mia0x75/denyzer/internal/benchregexp"
)

func main() {
    n := flag.Int("n", 1000, "number of regexes")
    shape := flag.String("shape", "oisd", "pattern shape: oisd or prefix")
    flag.Parse()

    patterns := make([]string, *n)
    for i := range patterns {
        if *shape == "prefix" {
            patterns[i] = fmt.Sprintf(`^regex%d\..*$`, i)
        } else {
            patterns[i] = fmt.Sprintf(`^(.*\.)?domain%d\.example\.com$`, i)
        }
    }

    start := time.Now()
    compiled := make([]*benchregexp.Regexp, 0, len(patterns))
    for _, pattern := range patterns {
        r, err := benchregexp.Compile(pattern)
        if err != nil {
            panic(err)
        }
        compiled = append(compiled, r)
    }
    runtime.KeepAlive(compiled)

    var stats runtime.MemStats
    runtime.ReadMemStats(&stats)
    matched := false
    if len(compiled) > 0 {
        matched = compiled[len(compiled)-1].MatchString("a.domain999.example.com")
    }
    fmt.Printf(
        "engine=%s shape=%s n=%d compile_ns=%d heap_alloc=%d heap_sys=%d rss_kb=%d match=%v\n",
        benchregexp.Engine, *shape, *n, time.Since(start).Nanoseconds(),
        stats.HeapAlloc, stats.HeapSys, rssKB(), matched,
    )
}

func rssKB() int64 {
    data, err := os.ReadFile("/proc/self/status")
    if err != nil {
        return -1
    }
    for _, line := range strings.Split(string(data), "\n") {
        fields := strings.Fields(line)
        if len(fields) == 3 && fields[0] == "VmRSS:" {
            value, _ := strconv.ParseInt(fields[1], 10, 64)
            return value
        }
    }
    return -1
}
